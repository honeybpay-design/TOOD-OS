# Architecture decision records

Each decision is a file `NNNN-title.md` with context, decision, alternatives, consequences and review condition.
Decisions marked **must not be weakened** change only through a new ADR with named human approval (blueprint section 32).

| ADR | Decision | Review condition |
|---|---|---|
| 0001 | Modular monolith | A module needs to scale very differently from the rest |
| 0002 | Postgres with pgvector, single database | Vectors above 10 million or search latency above 300 ms |
| 0003 | Postgres-backed job queue first | Job volume or workflow complexity outgrows it |
| 0004 | Auth library inside the API service | Enterprise customers require SAML or SCIM |
| 0005 | AI Gateway with UK/EU residency guard | none |
| 0006 | Verbatim check and claim verification mandatory | **Must not be weakened** |
| 0007 | Provenance at creation, hash chain, external anchoring | **Must not be weakened** |
| 0008 | Models pass the Admission Test before use | **Must not be weakened** |
| 0009 | No automatic bid submission | **Must not change** |
| 0010 | AI Use Record generated by code, never by AI | **Must not change** |
